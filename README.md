# Violet Client (Fabric 1.21.11, Yarn)
Build: `gradle wrapper --gradle-version 9.2.1` then `./gradlew build` -> build/libs/violet-1.0.0.jar
Or copy `src/` + `build.gradle` + `gradle.properties` into the official Fabric template for 1.21.11.
Open menu: Right Shift. Zoom: hold C. Config: config/violet.json (saved when menu closes).
